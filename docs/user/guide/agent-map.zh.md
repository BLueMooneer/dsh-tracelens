# 使用 Agent Map 检查会话

[English](agent-map.md) | 中文

Agent Map 已包含在仓库的 Web profile 中。它为现有会话数据提供紧凑的可视化投影；不会运行另一个 agent，也不会改变会话。

## 启动 Web UI

在仓库源码目录中构建并启动 Web profile：

```sh
pnpm install
pnpm run build
pnpm dsh web
```

打开命令输出的地址，选择工作区，然后打开或创建会话。在会话视图切换器中选择 **Agent Map**。

## 阅读图形

五条泳道分别展示输入、模型输出、工具活动、系统记录和失败。每张卡片对应浏览器当前已加载会话窗口中的一条已完成或进行中记录。

- 灰线连接事件日志中相邻的记录；它不表示前一条记录导致了后一条记录。
- 只有 Assistant 工具请求和结果包含相同的明确 `callId` 时，才使用蓝线连接它们。
- 悬停或使用键盘聚焦任一种关系线，即可查看其类型和因果语义。
- 运行中状态可能表示冻结的局部 Assistant 响应，或尚未结束的工具调用。
- 失败状态包括工具错误、中断的 Assistant 输出、已取消的模型重试、轮次错误和最大 token 终止。

计数器只描述可见记录。如果标题提示已加载窗口限制，请先从 Chat 或 Trajectory 加载更早的历史，再把这些数字当作会话总数。

## 检查节点

使用指针选择节点，或聚焦节点后按 Enter 或空格键。详情卡会直接在该节点下方打开，不再占用画布右侧空间。每张卡都会显示状态、时间、可用的事件序号、轮次／步骤坐标和传入关系，再按类型补充已记录字段：消息内容与来源；模型提供方、请求配置、耗时、推理和工具调用；工具参数、结果、耗时、错误、元数据和直接子调用；以及相应的命令、压缩、重试和失败数据。工具参数、工具结果、模型推理和模型工具调用会在浅色内容面板中使用近黑色文字，便于阅读长内容。**直接子调用数**只统计 Code Mode 派发产生的嵌套调用，不统计后续普通工具调用；数量为零时不显示该字段。标题只显示一次。点击所选节点及其附属卡片以外的任意位置即可关闭详情。`edit`、`write` 等纯工具调用 Assistant 记录仍会作为模型泳道节点显示，并通过 `callId` 连接相应工具节点。

## 比较 Token 用量

左侧只保留紧凑的两行两列计数器，右侧缩放控件使用更窄的按钮组。加高后的顶部 Token 仪表盘会占满两者之间的全部剩余空间，并使用更大的标题、总量文字和更粗的比例条。展开列表与仪表盘同宽，只显示每次调用的总量和占比。选择模型回复后，对应分段会高亮，其他分段降低亮度；选择顶部某个分段也会选中画布中的准确对应节点。节点上方会打开同样采用玻璃详情效果的 2×2 Token 卡，分别显示 `inputTokens`、`outputTokens`、`cacheReadTokens` 和 `reasoningTokens`。节点未选中时完全不显示该卡。`cacheWriteTokens` 仍计入总量，但不增加第五格。`reasoningTokens` 已包含在 `outputTokens` 中，因此只展示而不重复加入总量。纯工具调用模型记录保持可见，因此每个仪表盘分段都有一个模型泳道对应节点。如果更早历史尚未加载，总量与占比都只覆盖当前已加载窗口。

## 适应和缩放画布

Agent Map 默认处于**适应**模式，图形能容纳时比例为 100%。新节点到达或视口变化时，比例会自动重新计算，最低为 30%。图形在 30% 时仍需更多空间，就保持 30% 并允许拖动，而不是继续缩小。使用**放大画布**或**缩小画布**会进入手动模式；更多节点到达时，选定比例保持不变。按住画布空白处可以横向或纵向拖动工作流，也可以拖动输入框上方的滚动条精确横向定位；两种操作会保持同步。紧凑泳道标签固定在左侧。选择**适应**可恢复自动适应并重置拖动位置。节点始终可以点击；每次缩放或拖动期间，详情卡都会继续附着在所选节点下方。

## 在其他组合中启用

仓库 Web profile 默认启用 Agent Map。自定义浏览器组合必须先提供 locale、runtime 和 conversation UI，再把 `@deepseek-ai/dsh-client-ui-agent-map` 加入客户端插件列表。不要为它注册第二套会话投影：该插件使用现有的会话作用域 `conversation.view` 快照。

修改源码后，如果没有运行 bundle watcher，请重新构建该包并重启 Web 进程：

```sh
pnpm --filter @deepseek-ai/dsh-client-ui-agent-map bundle
pnpm dsh web
```

## 故障排查

- **没有 Agent Map 页签：**确认当前组合包含该包，并且已经构建其客户端 bundle。浏览器启动错误会指出缺失的注入客户端提供方。
- **图形为空：**打开非空会话或发送一条消息；已加载会话为空时，显示空状态是正确行为。
- **计数看起来太少：**检查是否存在已加载窗口提示，并从 Chat 或 Trajectory 加载更早的前缀。
- **长任务结束后节点太小：**使用**放大画布**，然后按住画布空白处拖动并检查放大的图形；选择**适应**可重新查看完整的已加载图形。
- **某条灰线看起来没有关联：**该连线只表达顺序。只有由 `callId` 支撑的蓝线才表示工具请求／结果关系。
- **最近的源码修改没有显示：**运行上面的包构建命令，然后重新加载页面或重启 Web 进程。

实现和扩展规则参见[包 README](../../../packages/client/ui-agent-map/README.md)。
