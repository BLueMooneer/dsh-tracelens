# @deepseek-ai/dsh-client-ui-agent-map

[English](README.md) | 中文

Agent Map 为 Web 会话页面增加交互式执行地图。它将浏览器公开的会话快照投影到输入、模型、工具、系统和错误五条水平泳道中，不增加宿主服务、会话事件或第二套会话投影。

该包属于仓库的 `web` profile。启动该 profile 并打开会话后，现有会话视图旁会显示 **Agent Map** 页签。操作和故障排查参见[使用手册](../../../docs/user/guide/agent-map.md)。

## 地图显示的内容

- 当前已加载会话窗口中的已完成会话记录、冻结的局部 Assistant 响应和运行中的工具调用。
- 可见节点、轮次、工具和失败数量。
- 选中节点下方直接弹出的详情卡。通用字段包含状态、时间、序号、轮次／步骤位置和传入关系；类型专属字段会按记录展示消息内容与来源、模型请求／耗时／推理、工具参数／结果／错误、命令结果、压缩统计或重试数据。工具参数、工具结果、模型推理和模型工具调用统一在浅色内容面板中使用近黑色文字，确保两种宿主主题下的长内容都易于阅读。只有会话投影记录到一个或多个 Code Mode 嵌套派发时，工具结果才显示**直接子调用数**；普通工具调用会正确省略该字段。点击所选节点及其附属卡片以外的位置即可关闭。
- 占满页头剩余空间的全对话 100% 堆叠用量条。悬停或聚焦仪表盘只显示每次调用的准确总量和占比；选择模型节点会高亮对应的条形分段。
- 从 100% 到最低 30% 的实时适应视口缩放、手动缩放控件、指针和 Enter／空格键选择、同步的底部滚动条，以及无障碍图形标签。

灰线只表示相邻记录按事件日志顺序出现。蓝色工具连线表达更强的事实：某个 Assistant 块明确给出了目标工具调用的准确 `callId`。地图绝不根据时间、文本或距离推断因果关系。如果更早的历史尚未加载，标题会说明图中只包含已加载的会话窗口。

## 画布缩放

图形能以原始尺寸容纳时从 100% 开始。节点到达或周围布局变化时，图形会测量可用宽高并自动适应，但最低只缩小到 30%；超过该下限的宽图保持可拖动，不会继续缩小到难以阅读。**放大画布**和**缩小画布**会进入有界的手动比例；更多节点到达时，该比例保持不变。按住画布空白处可以横向或纵向拖动工作流，也可以使用底部滚动条精确横向移动；画布拖动位置与滚动条双向同步。**适应**会返回实时适应模式并重置拖动位置。五个紧凑泳道名称保留在固定左栏中，不会随 SVG 缩放或横向移动。缩放和拖动期间，节点 id、选择状态、键盘焦点和附着在所选节点下方的详情卡都保持稳定。

只包含工具调用块的 Assistant 记录仍会显示在模型泳道中，从而保证顶部每个 Token 分段在画布中恰好对应一个节点；其已记录的 `callId` 也会标记并连接相应工具节点。

## Token 用量

每个已完成 Assistant 的 `usage` 样本会在公开快照入口接受校验，总量等于未缓存输入、输出、缓存读取和缓存写入之和。`reasoningTokens` 会显示，但由于它已经包含在 `outputTokens` 中，不会再次加入总量。选择模型回复后，节点上方会打开 2×2 Token 卡，分别显示 `inputTokens`、`outputTokens`、`cacheReadTokens` 和 `reasoningTokens`，同时高亮同一次调用的仪表盘分段并降低其他分段亮度；选择仪表盘分段也会选中同一个画布节点。`cacheWriteTokens` 仍计入总量，但不占用固定四格快速卡。加高后的仪表盘使用更大字体，其展开列表与仪表盘保持同宽。仪表盘以这些已加载模型调用的总和为分母，其中包含纯工具调用 Assistant 记录，因此每个分段都有一个可见的模型泳道节点。它描述当前已加载会话窗口，而不是隐藏的完整历史总量。没有已记录 usage 样本的调用不会被估算。

页面使用宿主主题的语义颜色，而不是固定的亮色或暗色值：节点强调色、状态文字、焦点轮廓、连线光晕、玻璃质感表面和画布网格都能在两种外观模式中保持层级。缓慢极光、扫描光束、流动工具连线、运行节点信标、选中节点电路边框和详情卡空间展开共同形成 HUD 动效，不改变图形几何或 React 状态。`prefers-reduced-motion` 会关闭全部持续动画和入场动画。每个节点仍以文字显示状态，颜色不是唯一提示。

## 组合与依赖顺序

客户端 manifest 声明了 locale、runtime 和 conversation UI 注入。Web 组合包必须先加载这些提供方，该插件才能贡献视图。注册本身使用 `ctx.slots.inject('conversation.view', ...)`，因此 slot 声明也可以稍后出现，Cordis 仍会在声明的生命周期内激活该贡献。返回的 disposer 会在该生命周期结束时移除视图，所以重新加载不会积累重复页签。

仓库的 Web profile 已包含该包。其他组合必须在浏览器插件列表中包含 `@deepseek-ai/dsh-client-ui-agent-map`，并提供：

- `@deepseek-ai/dsh-client-locale`
- `@deepseek-ai/dsh-client-runtime`
- `@deepseek-ai/dsh-client-ui-conversation`

## 开发

纯投影位于 [`src/client/graph.ts`](src/client/graph.ts)，React 视图位于 [`src/client/AgentMapView.tsx`](src/client/AgentMapView.tsx)，本地化产品文案位于 [`src/client/locales.ts`](src/client/locales.ts)。新增关系必须由权威标识符支撑。如果新视觉效果所需数据不在 `ConversationSnapshot` 中，应扩展所属的会话投影，不要扫描无关状态或根据相邻记录猜测。

在仓库根目录运行针对性检查：

```sh
pnpm exec tsc -b packages/client/ui-agent-map
pnpm exec vitest run packages/client/ui-agent-map/tests
pnpm --filter @deepseek-ai/dsh-client-ui-agent-map bundle
```

会话视图变更还需要真实组装的 Web 快照、相关 GUI 检查、双语文档，以及变更表面对应的仓库门禁。

## 模型体验

无。Agent Map 在浏览器中渲染已有会话数据；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **没有历史分页控件** — 地图会报告尚未加载的前缀，但用户需要从 Chat 或 Trajectory 加载该前缀。
- **没有分支比较或推断依赖** — 图中只显示一个会话，并且缺少明确标识符时不会虚构关系。
- **大型窗口使用单个 SVG 画布** — 浏览器开销随已加载事件窗口增长；只有实测会话证明值得增加交互复杂度后，才会引入虚拟化图块。
