# Agent Note: Agent Map 会话视图

Status: implemented

[English](2026-08-14-agent-map-conversation-view.md) | 中文

## 问题

Trajectory 保存了详细的时间顺序记录，但用户仍然需要逐行阅读，才能理解人工输入、模型输出、工具活动、系统工作和失败在一个会话中如何关联。用另一条时间线替换 Trajectory 会重复其职责，却仍然无法回答这种关系问题。若日志只能证明顺序，可视化视图还可能夸大因果关系。

## 决策

`@deepseek-ai/dsh-client-ui-agent-map` 向既有 `conversation.view` 环贡献会话作用域的 `agent-map` 配置项。组件根据 UI Conversation 已经组装的公开会话快照派生一个 SVG 图。它不注册 host 服务、持久事件、Conversation Node Definition 或独立视图目标。

图中使用输入、模型、工具、系统和错误五条稳定的语义泳道。最终会话节点、冻结的局部助手输出和进行中的工具调用按照已加载窗口的顺序成为节点。灰色边只表示相邻日志顺序。蓝色边要求助手工具块与工具节点具有相同的 `callId`；UI 绝不会把时间相邻标记为因果关系。

图模型、几何布局和适应比例计算都是 React 外部的纯函数。适应模式从原始 100% 比例开始，以 30% 作为可读性下限；超过该下限的溢出通过拖动画布查看。组件拥有选择状态、手动比例和视口拖动状态，通过框架提供的会话钩子读取实时数组，并通过 slot locale seat 接收本地化文本。视口观察器会在适应模式中重新计算比例；图形几何变化时，手动模式保持其比例。独立的底部滚动条与指针拖动会双向更新同一视口位置，画布的两个轴都使用宿主滚动条皮肤。紧凑泳道名称渲染在固定同级栏中，SVG 则独立拖动。选中节点在自身下方拥有唯一详情卡，其中显示通用坐标和该类型已记录的专属数据；在节点及其附属卡片外按下指针会清除选择。长工具参数、工具结果、模型推理和模型工具调用会在两种主题中使用浅色内容面板与近黑色文字。只有 Code Mode 嵌套派发投影非空时，工具结果才显示直接子调用数，避免普通调用出现容易误解的零。只包含工具调用块的 Assistant 记录保留模型泳道节点，其 `callId` 会把匹配的工具节点标记为工具关系。经过校验的 Assistant usage 会在两行计数网格与紧凑缩放控件之间形成加高且占满剩余宽度的已加载窗口 100% 堆叠仪表盘，其同宽展开列表只提供总量与占比。每个仪表盘分段使用对应模型节点 id：选择节点会高亮该分段，激活分段则会选择节点。所选模型节点上方显示玻璃效果的 2×2 快速卡，内容为输入、输出、缓存读取和推理用量。缓存写入仍计入总量但不增加第五格；由于输出已包含推理，总量不会重复加入推理字段。缺少 usage 样本的调用不会估算。主题语义颜色控制两种外观模式中的网格、半透明表面、节点强调色、状态与焦点处理以及工具连线光晕；文字状态确保含义不依赖颜色。纯 CSS 的极光、扫描、连线流动、运行、选择和详情入场效果不会更新图形状态，reduced-motion 查询会关闭全部这些动效。缩放和拖动都不会替换图形节点或选择状态。slot 声明注入拥有注册和 dispose（资源释放），CSS Modules 则拥有响应式展示和 reduced-motion 行为。

## 考虑过的替代方案

**给 Trajectory 增加图模式。** Trajectory 拥有详细事件检查、计时、分页和搜索。加入关系画布会耦合两种不同的阅读任务，也会导致两者无法独立安装或移除。

**注册另一套完整的 Conversation 事件投影。** 当视图需要 Chat 未保留的事实时，目标专属投影是合适方案。Agent Map 使用所属视图环已经需要的公开最终记录和进行中记录，因此另一组事件状态机会重复生命周期规则，并可能与可见会话发生偏差。

**根据顺序、时间或文本推断因果边。** 这些信号无法证明一个操作导致另一个操作。已实现的图只为记录了相同 `callId` 的关系保留更强的工具边，并把其余连接都标记为时间流。

**采用图组件依赖。** 该视图需要固定泳道、曲线边、适应缩放、手动缩放和选择，而不需要任意节点拖动或自动布局。小型 SVG 投影能够保持较窄的浏览器 bundle 和运行时依赖集合；如果实测需求增加大图虚拟化、可编辑拓扑或自由平移，仍可采用受维护的图库。

## 后果

Web 组合包增加了第三个会话视图，它可以解释已加载的会话，而不改变模型可见的 transcript（文本记录）或提供方请求。用户可以区分记录在案的工具关系与单纯执行顺序，在节点到达时让完整的已加载图形保持可见，改变比例，并且不离开图即可检查节点。该包依赖 UI Conversation 存在：所属 owner 缺失时，其 slot 注入保持休眠，并在重新加载期间跟随该声明。

更早页面尚未加载时，该视图有意不充当完整会话图，也不比较 fork，并在单个 SVG 画布中挂载已加载记录。这些限制写入包 README，从而避免隐藏分页、推测因果和过早引入图基础设施。
